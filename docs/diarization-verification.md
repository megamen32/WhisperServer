проходит успешно. Токен остаётся только в серверном `.env`.

2277 и 777) модель автоматически определила двух говорящих и верно сохранила
метку первого при его возвращении. Контрольная запись 25,04 секунды;
CPU inference 28,13 секунды, пик памяти cgroup 948547584 байт.

звука, автоматическое определение объединило голоса. Это наблюдаемое
ограничение, а не гарантированная точность для любой записи.
